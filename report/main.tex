\begin{abstract}
Knowing how much additional traffic a path can absorb before performance degrades is central to network management, yet current practice often answers this question by monitoring scalar delay metrics such as mean round-trip time or percentile latency and raising alerts when these cross predefined thresholds. These summaries discard distributional information that encodes how path conditions are changing. This report evaluates a passive monitoring system that treats the delay distribution itself as the object of interest. The evaluation first studies the statistical sample complexity behind distribution reconstruction, then evaluates an adaptive stopping rule that decides when enough samples have been collected without using ground truth at deployment time.
\end{abstract}

\chapter{Methodology}

The methodology treats passive delay monitoring as two linked statistical tasks: reconstruction and identification. Reconstruction estimates the full distribution of packet delays observed at the receiver, instead of reducing a path to a scalar delay statistic. Identification uses that reconstructed distribution to decide whether the path appears to be in a particular operating state, such as a safe capacity regime or a degraded regime. This chapter sets out the common method used across the evaluation. The first two evaluation sections focus on reconstruction and stopping, while the later use-case section uses identification to turn the reconstructed distribution into an operational decision.

\section{Problem framing}
\label{sec:method-problem-framing}

The object of interest is the delay distribution induced by a network path over a measurement interval. Let \(X_1,\ldots,X_n\) denote independent delay observations drawn from an unknown distribution \(P\). In the simplest direct-sampling experiments, these observations are generated from a known distribution family in order to isolate the statistical question. In the network experiments, they are packet delays produced by Network Simulator 3 (NS-3). In both cases, the monitor receives only the samples. The distribution family and its parameters are not given to the reconstruction algorithm.

This framing separates estimation from validation. The monitor constructs an estimate \(\widehat{P}_n\) from the observed samples alone. Ground truth is used only after reconstruction, in order to evaluate whether the estimate is accurate. This distinction is central to the project: the deployment setting is passive and distribution-agnostic, while the experimental setting uses known ground truth to measure performance.

Identification enters after this reconstruction step. In the use-case setting, the question is no longer only whether \(\widehat{P}_n\) is close to the hidden ground truth. It is whether the observed delay distribution is consistent with a reference state, or sufficiently different from it to indicate that the path has moved into a different capacity regime. This is closer to identity testing or goodness-of-fit testing in the terminology of distribution testing. The statistical sample-complexity evaluation does not use that testing result directly, because it first has to establish that the reconstructed distribution is reliable enough to support later identification decisions.

The methodology is deliberately staged. Direct sampling is used first because it removes packet scheduling, queueing, and simulator effects. This establishes whether the statistical reconstruction problem behaves as expected. The method is then applied to simulated packet delays, where the same reconstruction and stopping rules are tested under network conditions. The later use-case, multi-hop, and multi-path experiments are intended to increase network complexity without changing the monitoring interface.

\section{Observation model}
\label{sec:method-observation-model}

The passive monitor observes packet delays at the receiver. In the non-binning setting used as the clean baseline, each packet contributes one delay sample. This is the least lossy version of the problem because the estimator can use the observed delays directly. Where a finite-domain comparison is required, the observed delays are mapped onto a delay grid. A bin is a fixed-width interval of delay values, and the number of bins determines the number of probabilities that must be estimated.

The main continuous grid used in the evaluation has one millisecond bins from 0 milliseconds to 150 milliseconds, giving 150 cells. This range is wide enough for the configured normal, lognormal, and Weibull delay distributions used in the current experiments. Discrete experiments use their natural finite supports, so no additional delay grid is needed. The binning step is therefore not a claim that delay is intrinsically discrete. It is a measurement and evaluation device that allows continuous reconstructions to be compared using the same finite-domain distance.

In the simple network case, the topology is a two-node, one-link path. Node A sends packets to Node B, and the link delay is sampled independently for each packet from the configured delay distribution. This setup gives direct control over the ground truth while still exercising the packet-level measurement pipeline. More complex topologies can be introduced later by changing how the path generates observed delays, rather than by changing the reconstruction objective.

\section{Distribution reconstruction}
\label{sec:method-distribution-reconstruction}

The reconstruction method depends on whether the target distribution is being represented as a finite probability mass function or as a smoothed continuous estimate. For discrete data, the estimator is the empirical probability mass function (PMF). If \(\mathcal{X}\) is the support, the estimate assigns each value \(x \in \mathcal{X}\) its observed relative frequency:
\[
\widehat{P}_n(x)=\frac{1}{n}\sum_{i=1}^{n}\mathbf{1}\{X_i=x\}.
\]
This estimator is simple, distribution-agnostic, and directly aligned with the finite-domain learning theory used in the evaluation.

For continuous delays, two reconstructions are considered. The first is a binned empirical PMF, obtained by counting how many samples fall into each delay bin. This gives a finite representation that can be compared directly with true bin probabilities. The second is a kernel density estimate (KDE). The KDE evaluates a smooth density from the samples, then converts that density back into probability mass on the same delay grid for comparison. This allows the evaluation to test whether smoothing improves sample efficiency without assuming that the monitor knows the generating family.

The estimators are intentionally non-parametric. The monitor does not fit a normal, lognormal, Weibull, binomial, Zipfian, or piecewise model. Those families are used to generate controlled ground truth distributions, not to constrain the reconstruction. This is important because the eventual monitoring setting should not require the operator to know the delay distribution in advance.

\section{Accuracy metrics}
\label{sec:method-accuracy-metrics}

The primary accuracy metric is total variation distance (TVD). For two distributions \(P\) and \(Q\) over the same finite domain \(\mathcal{X}\),
\[
d_{\mathrm{TV}}(P,Q)=\frac{1}{2}\sum_{x\in\mathcal{X}}|P(x)-Q(x)|.
\]
TVD is used because it has a direct interpretation as the largest probability difference that the two distributions assign to any event. It is also the distance used by the finite-domain learning bound that motivates the sample-complexity experiments.

For continuous distributions, TVD is computed after both the true distribution and the estimate have been represented on the same finite grid. The true probability of a bin is computed from the known cumulative distribution function in direct-sampling experiments, or from the simulator's configured ground truth where available. The estimated probability is computed either from the empirical bin counts or from the grid-normalised KDE. This keeps the metric consistent across discrete and continuous cases.

Kullback-Leibler divergence and Wasserstein distance are secondary diagnostics. They provide complementary views of reconstruction quality, but they are not the primary success criterion. Kullback-Leibler divergence is sensitive to small probabilities and can become unstable when an estimated bin has zero mass. Wasserstein distance captures geometric movement of probability mass across the delay axis, which is useful for delay distributions, but it is not the distance used in the sample-complexity theorem. The evaluation therefore reports and discusses TVD first.

\section{Sample complexity and stopping}
\label{sec:method-sample-complexity-stopping}

The statistical part of the methodology uses finite-domain distribution learning as a reference point. For a distribution over \(k\) outcomes, the number of samples needed to learn the distribution within TVD \(\delta\) with failure probability at most \(\varepsilon\) scales as
\[
n=\Theta\left(\frac{k+\log(1/\varepsilon)}{\delta^2}\right).
\]
This bound is used as a conservative theoretical baseline. It explains why finer grids require more samples and why stricter accuracy targets become expensive quickly. It is not treated as a deployment rule, because it protects against arbitrary worst-case distributions and can be much larger than the empirical requirement for structured delay distributions.

The adaptive stopping method addresses that gap. Samples are processed in batches. After each batch, the monitor compares the current reconstruction with the previous reconstruction using TVD. If the change between the two estimates is below a chosen stability threshold, the monitor stops. The stopping decision uses only observed samples and previous estimates. Ground truth is not used at stopping time.

The stopping rule converts the offline sample-complexity question into an online monitoring question. The offline question asks how many samples would be sufficient if the ground truth were known for evaluation. The online question asks whether the monitor can detect that its estimate has stabilised before collecting a worst-case number of samples. The evaluation tests this by recording both the stopping time and the post-hoc TVD against the true distribution.

This creates the iterative loop used in the dissertation. Theory gives a conservative reference point. Direct sampling checks whether the estimator behaves sensibly before any network effects are introduced. Adaptive stopping then asks how quickly the estimator can be trusted without ground truth. The use case will use that trusted estimate for identification. If a later network experiment fails, the loop makes the failure easier to diagnose: the cause is less likely to be basic distribution learning, and more likely to be the network mechanism, the stopping threshold, or the identification boundary.

\section{Experimental workflow}
\label{sec:method-experimental-workflow}

Each experiment follows the same workflow. A ground truth distribution is selected, samples are generated, a reconstruction is built from those samples, and the reconstruction is compared with ground truth. Random seeds are used to repeat each configuration so that the reported behaviour reflects sampling variability rather than a single run. Median values and interquartile ranges are used in the plots because they show the central trend and the spread across seeds without being dominated by isolated runs.

The first evaluation uses direct sampling from discrete and continuous distributions. The discrete cases are binomial, Zipfian, and piecewise distributions. The continuous cases are normal, lognormal, and Weibull distributions. This stage validates the statistical method independently of the network simulator. The second evaluation uses the same distribution families to test adaptive stopping. It asks whether stability between consecutive reconstructions is a reliable proxy for accuracy against ground truth.

The later evaluations will use the same measurement and reconstruction pipeline in increasingly realistic network settings. The motivating use case will connect distribution reconstruction to the operational question of remaining path capacity. The multi-hop and multi-path studies will test whether the method remains informative when the observed delay distribution is produced by multiple links or multiple path components. This structure keeps the dissertation aligned: each evaluation changes the source of the observed samples, while the central object of estimation remains the delay distribution.

\section{Reproducibility}
\label{sec:method-reproducibility}

The implementation separates data generation, analysis, and report figures. Simulation and experiment launch scripts live under the project scripts directory, while analysis scripts live under the analysis directory. Generated data are kept under the results directory, and report-ready figures are copied into the report figure directory. This separation makes it possible to rerun an experiment, regenerate its summary data, and update the dissertation figures without changing the prose manually.

The current methodology relies on fixed parameter choices for comparability across experiments. The main TVD target is 0.05, the main failure probability for the sample-complexity reference is 0.05, and the continuous delay grid uses one millisecond bins over 0 to 150 milliseconds. These choices are not inherent limits of the method. They provide a consistent baseline so that changes in performance can be attributed to the distribution shape, estimator, sample count, or stopping configuration rather than to changing evaluation definitions.

\section{Statistical sample complexity}
\label{sec:eval-statistical}

The first evaluation asks how many samples are needed before an unknown delay distribution can be reconstructed accurately. This part deliberately removes the network simulator from the loop. Samples are drawn directly from the configured distributions so that the statistical claim can be tested before any network effects are added. The monitor sees only samples. It is not told whether they came from a binomial, Zipfian, piecewise, normal, lognormal, or Weibull distribution.

The main accuracy metric is total variation distance (TVD). For a true distribution \(P\) and an estimate \(\widehat{P}\) over a finite domain \(\mathcal{X}\), this is
\[
d_{\mathrm{TV}}(P,\widehat{P}) =
\frac{1}{2}\sum_{x \in \mathcal{X}} |P(x)-\widehat{P}(x)|.
\]
A reconstruction is treated as successful when this distance is at most a target error \(\delta\), with failure probability at most \(\varepsilon\). Throughout this section, \(\delta=0.05\) and \(\varepsilon=0.05\), so the target is reconstruction within 5 percent TVD with probability at least 0.95.

\subsection{The learning bound}

The theoretical reference point comes from finite-domain distribution learning. Canonne's monograph on distribution testing records this as the learning baseline for arbitrary distributions on a known finite domain, and uses it as the benchmark against which sublinear testing algorithms are compared \cite{canonneTopics}. Canonne writes the TVD tolerance as \(\varepsilon\) and the failure probability as \(\delta\). Using this report's notation, where \(\delta\) is the TVD target and \(\varepsilon\) is the failure probability, independent samples from an unknown distribution over \(k\) possible outcomes are sufficient for the plug-in histogram estimator to learn the distribution in TVD with sample complexity
\[
n = \Theta\left(\frac{k+\log(1/\varepsilon)}{\delta^2}\right).
\]
This is an information-theoretic finite-sample bound, tight up to universal constants for arbitrary distributions on \(k\) categories \cite{canonneShort,canonneTopics,devroyeLugosi}. The base of the logarithm affects only constants in the asymptotic theorem; the numerical calculations below use the natural logarithm. The \(k\) term is the number of probabilities that must be estimated. The \(1/\delta^2\) term comes from concentration: halving the desired error requires roughly four times as many samples. The \(\log(1/\varepsilon)\) term pays for high probability rather than only average-case accuracy.

This is the correct baseline for the first evaluation because that experiment studies reconstruction accuracy. It asks how well the empirical distribution itself has been learned. Identification is still part of the project, but it belongs to the use-case stage rather than to this statistical-theory stage. Once the use case has a reference operating state, the monitor can ask an identity-testing style question: whether the current delay distribution is consistent with that reference, or far enough away to indicate a capacity change \cite{canonneSurvey}. The reconstruction evaluation comes first because identification decisions are only meaningful if the distribution estimate feeding them is stable.

The word finite is important. A discrete distribution already has a finite support. A continuous delay distribution has to be evaluated on a finite grid before TVD can be computed as a sum. A bin is one such grid cell. In the continuous experiments below, one bin corresponds to a one millisecond interval, and all bins from 0 milliseconds to 150 milliseconds are used. This gives \(k=150\) categories. Once the continuous distribution has been converted into bin probabilities, the same finite-domain comparison applies.

The experiments use the explicit reference value
\[
n_{\mathrm{theory}} =
\left\lceil \frac{k+\log(1/\varepsilon)}{\delta^2} \right\rceil .
\]
With \(\varepsilon=0.05\), \(\log(1/\varepsilon)=\log(20)=2.996\). The corresponding theory curve in the plots is the same relationship inverted as
\[
\delta_{\mathrm{theory}}(n)=
\sqrt{\frac{k+\log(1/\varepsilon)}{n}}.
\]
The curve should be read as a distribution-free reference, not as a prediction that every structured distribution will need exactly that many samples. The main empirical pattern to look for is therefore not equality between the curves, but whether TVD falls with \(n\), whether harder shapes converge more slowly, and whether the target is reached no later than the calculated reference point. The insight is methodological as much as numerical: if direct sampling already failed this check, later network experiments would not be interpretable. Passing it means the later experiments can focus on stopping, use-case identification, and topology effects rather than on whether the estimator is fundamentally mis-specified.

\subsection{Discrete sampling}

The discrete experiment uses three finite distributions, shown in the top row of Figure \ref{fig:statistical-distribution-shapes}. They were chosen because the theorem is stated directly for finite domains, and because they stress different forms of discrete structure. The binomial distribution is smooth and concentrated. The Zipfian distribution is highly skewed and has a long finite tail of rare outcomes. The piecewise distribution is deliberately irregular and multi-modal, so it tests a case where there is no smooth ordering for the estimator to exploit.

The binomial case uses
\[
X \sim \mathrm{Binomial}(20,0.5),
\qquad
p(x)=\binom{20}{x}0.5^x0.5^{20-x},
\qquad x \in \{0,\ldots,20\}.
\]
This gives \(k=21\) possible outcomes. The Zipfian case uses a truncated power law,
\[
p(x)=\frac{x^{-1.5}}{\sum_{j=1}^{20}j^{-1.5}},
\qquad x \in \{1,\ldots,20\},
\]
so \(k=20\). The piecewise case also uses support \(\{1,\ldots,20\}\), with probabilities indexed in support order as
\[
\begin{aligned}
p = (&0.12,0.02,0.08,0.01,0.10,0.03,0.07,0.12,0.02,0.09,\\
     &0.01,0.08,0.04,0.06,0.02,0.05,0.02,0.04,0.01,0.01).
\end{aligned}
\]
The values sum to one and create separated high-probability regions.

For each distribution, samples are drawn directly from the probability mass function (PMF). The estimator is the empirical PMF. Each point in Figure \ref{fig:statistical-discrete-tvd} is the median TVD over 100 random seeds, and the shaded band is the interquartile range. The tested sample sizes are centred around the calculated \(n_{\mathrm{theory}}\) value for each support size.

The calculation for the binomial case is
\[
n_{\mathrm{theory}} =
\left\lceil \frac{21+\log(20)}{0.05^2} \right\rceil
=
\left\lceil \frac{23.996}{0.0025} \right\rceil
= 9{,}599.
\]
For the Zipfian and piecewise cases, \(k=20\), so
\[
n_{\mathrm{theory}} =
\left\lceil \frac{20+\log(20)}{0.05^2} \right\rceil
=
\left\lceil \frac{22.996}{0.0025} \right\rceil
= 9{,}199.
\]

Figure \ref{fig:statistical-discrete-tvd} shows the expected monotone decrease in TVD as \(n\) grows. The empirical curves all fall below the target well before the calculated reference point, but the ranking across distributions is meaningful. The binomial distribution is the easiest of the three. Although it has one more support point than the others, most of its mass is concentrated near the centre, so the low-probability tails contribute little to TVD. It first reaches the target at \(n=960\), and by \(n_{\mathrm{theory}}=9{,}599\) the median TVD is 0.0123.

The Zipfian distribution reaches the target at \(n=920\) and has median TVD 0.0132 at its theory point. Its head is easy to estimate because the first few outcomes carry most of the mass. The rare tail outcomes are harder individually, but their combined probability is limited, so errors in the tail do not dominate TVD. This is why the Zipfian curve is close to the binomial curve despite having a more uneven shape.

The piecewise distribution is the hardest discrete case. It is still below the theoretical reference by a wide margin, but it needs \(n=2{,}300\) samples before the median TVD falls below 0.05. This behaviour matches the design of the distribution. Probability mass is spread across separated peaks and troughs, so the empirical PMF has to learn several non-neighbouring support points accurately. The result is useful because it shows that the theoretical bound is not only conservative for smooth distributions. Even an irregular finite distribution reaches the target before the calculated distribution-free sample count, but it does so later than the smoother and more skewed alternatives.

This is the first point where the evaluation feeds back into the experimental design. The support size \(k\) alone does not determine the practical difficulty of reconstruction. The arrangement of mass across the support also matters. The piecewise distribution should therefore remain in the adaptive stopping and use-case experiments, because it is a better stress test for false stability than the binomial distribution. A stopping rule that only works for the smooth case would look good in a headline table but would not be robust enough for the later monitoring problem.

\subsection{Continuous sampling}

The continuous experiment uses the normal, lognormal, and Weibull distributions shown in the bottom row of Figure \ref{fig:statistical-distribution-shapes}. These are the same families used elsewhere in the project because they cover three different delay shapes. The normal distribution is symmetric and concentrated, representing a low-variability delay regime. The lognormal distribution is positive and right-skewed, which is a common shape for multiplicative delay effects. The Weibull distribution is also positive but has a different asymmetric shape, with a sharp rise and a longer decaying tail.

The parameter choices are
\[
X_{\mathrm{normal}} \sim \mathcal{N}(40,2^2),
\qquad
\log X_{\mathrm{lognormal}} \sim \mathcal{N}(2.3,0.2^2),
\qquad
X_{\mathrm{weibull}} \sim \mathrm{Weibull}(\lambda=10,\alpha=2).
\]
All samples are evaluated on the same one millisecond grid from 0 milliseconds to 150 milliseconds. The true binned distribution is computed by integrating the known cumulative distribution function over each bin. The empirical PMF counts how many samples fall in each bin. The kernel density estimate (KDE) is computed from the same samples, evaluated at the bin centres, and normalised so that it can also be compared as a probability mass function on the grid. This matters because TVD compares probability mass, not raw continuous density values.

The finite-grid comparison has \(k=150\), so the calculated bound is
\[
n_{\mathrm{theory}} =
\left\lceil \frac{150+\log(20)}{0.05^2} \right\rceil
=
\left\lceil \frac{152.996}{0.0025} \right\rceil
= 61{,}199.
\]
Each point in Figure \ref{fig:statistical-continuous-tvd} is the median across 30 random seeds, with interquartile shading.

The continuous results show the same broad pattern as the discrete results. TVD falls as the number of samples grows, and all three distributions are well below the target by the calculated \(n_{\mathrm{theory}}\). The empirical PMF reaches the target at 500 samples for the normal distribution, 1,000 samples for the lognormal distribution, and 2,000 samples for the Weibull distribution. The ordering is intuitive. The normal distribution places most mass in a narrow symmetric region, so the important bins are quickly populated. The lognormal distribution is skewed, which makes its right tail noisier. The Weibull distribution is the hardest for the binned PMF because its mass rises sharply near the lower end and then decays over a longer range, so the histogram has to estimate both a peak and a tail.

KDE changes this picture in the low-sample regime. It reaches the 0.05 target at the first tested point, 500 samples, for all three continuous distributions. This does not mean KDE has been given the parametric family. It only uses the local smoothness of nearby delay values. The empirical PMF treats adjacent one millisecond bins as unrelated categories, while KDE shares information across neighbouring values. That smoothing is especially helpful for Weibull, where the PMF median TVD is 0.0875 at 500 samples but the KDE median TVD is 0.0421.

At the theory point, both estimators are much more accurate than required. The binned PMF medians are 0.0047 for normal, 0.0052 for lognormal, and 0.0073 for Weibull. The KDE medians are 0.0060, 0.0057, and 0.0058. The small reversal for normal and lognormal, where the PMF is slightly closer than KDE at very large \(n\), is also expected. Once many samples have populated the bins, the empirical PMF has little variance left, while KDE still introduces a small amount of smoothing bias. The practical conclusion is therefore not that KDE always dominates PMF. It is that KDE is more sample efficient at the target accuracy used here, while PMF becomes competitive once the sample count is already large.

This comparison gives a concrete design choice for the next iteration. KDE is the right estimator to test for early continuous reconstruction because it buys sample efficiency without using a parametric assumption. The PMF remains useful as a finite-grid audit because it shows what can be learned without smoothing. The small large-\(n\) KDE bias also prevents an over-interpretation of the smoother curve: smoothing helps early stopping, but it should not be treated as ground truth when the use case needs a conservative capacity decision.

The gap between the binned PMF and KDE falls with \(n\), from 0.0704 to 0.0039 in the Weibull case and from roughly 0.03 to 0.003 in the normal and lognormal cases. This shows that KDE is not reconstructing a fundamentally different object. It is a smoothed version of the same empirical information, and the two estimates agree once enough samples are available.

The main implication for the monitor is that the theoretical bound is useful as a statistical backstop but too conservative as a stopping rule. It correctly identifies the dependence on support size, confidence, and error tolerance, and the empirical curves behave in the direction predicted by the theory. However, the direct-sampling distributions are far more structured than an arbitrary distribution over \(k\) unrelated cells. Their smoothness, concentration, and skew all affect how quickly TVD falls. This gap between worst-case theory and observed convergence motivates the adaptive stopping evaluation in the next section: instead of always waiting for \(n_{\mathrm{theory}}\), the monitor should stop when the estimate itself has stabilised.

The stronger lesson is that the project should not use the theory bound as a single answer to the sampling problem. The bound defines the safe outer envelope. The experiments identify which distribution shapes are hard, which estimator is worth using early, and which cases should be carried forward as stress tests. That is the intended iterative loop: theory sets the reference, direct sampling exposes estimator behaviour, adaptive stopping turns that behaviour into an online rule, and the use case then applies identification to decide whether the reconstructed delay distribution implies a capacity change.

The older delta-sweep, bin-resolution, KDE-disagreement, and Kolmogorov-Smirnov diagnostics are kept in Appendix \ref{app:statistical-diagnostics}. They support the same conclusion from a wider set of views: stricter TVD targets and finer grids increase the theoretical sample requirement, while the empirical structured distributions usually converge much earlier than the worst-case finite-domain reference.

\section{Adaptive stopping}
\label{sec:eval-adaptive}

The second evaluation asks how a passive monitor can decide when to stop collecting samples without access to ground truth. The statistical sample-complexity bound gives a conservative distribution-free reference point, but it is deliberately worst case. Used directly, it would turn the monitor into a system that waits for a guarantee long after the tested distributions have usually become accurate. The adaptive stopping rule tests a more operational idea: if adding more passive observations no longer changes the reconstructed distribution much, the estimate may be accurate enough to trust.

Samples are processed in groups of \(B\) packets, where \(B\) is the packets per batch parameter. After each new group of packets, the monitor computes the TVD between the current estimate and the previous estimate. If this inter-estimate TVD falls below a threshold \(\theta\), the monitor stops:
\[
\tau = \inf\left\{mB : d_{\mathrm{TV}}\left(\widehat{F}_{mB}, \widehat{F}_{(m-1)B}\right) < \theta\right\}.
\]
The stopping rule does not use the true distribution. Ground truth is used only after a run has stopped to evaluate whether the stopped estimate satisfies \(d_{\mathrm{TV}}(\widehat{F}_{\tau},F)\leq\delta\), where the target is \(\delta=0.05\).

The estimates in this rule are cumulative. With \(B=100\), the first comparison is between the reconstruction from samples 1 to 100 and the reconstruction from samples 1 to 200. The next comparison is between samples 1 to 200 and samples 1 to 300. The rule is therefore not comparing disjoint batches. It asks whether adding another batch changes the accumulated reconstruction enough to justify continuing. The batch size controls the spacing of these decisions: small batches give more opportunities to stop, while larger batches make each stability check less noisy.

The adaptive stopping sweep tests eight choices for packets per batch, \(B \in \{100,200,300,500,750,1000,1500,2000\}\), and six stability thresholds, \(\theta \in \{\delta/6,\delta/5,\delta/4,\delta/3,\delta/2,\delta\}\). Each configuration is evaluated over 100 random seeds. The continuous group uses the same normal, lognormal, and Weibull distributions as the sample-complexity experiment, reconstructed with a kernel density estimate (KDE) on the 1 ms grid. The discrete group uses a binomial distribution, a truncated Zipf distribution, and a hand-built multi-modal piecewise distribution over roughly 20 support points, reconstructed with a probability mass function (PMF) estimator.

The evaluation tests whether stability between consecutive estimates is a reliable proxy for accuracy against the true distribution. This matters because the previous section uses ground truth to measure when a reconstruction becomes accurate, but a deployed passive monitor cannot observe ground truth. The stopping rule is therefore useful only if it stops early while still meeting the TVD target with high probability.

The central trade-off is not simply speed against accuracy. It is the risk of mistaking local stability for global correctness. Small values of \(B\) give the monitor more opportunities to stop, but each decision is based on a small increment of new evidence. Loose thresholds amplify the same problem by accepting weak signs of stability. Continuous reconstruction and discrete reconstruction are separated because they fail for different reasons: the kernel density estimate can look stable while the smoothed peak or tail is still wrong, while the probability mass function estimate can look stable before enough mass has reached separated support points.

The primary adaptive metric is correctness, defined as the fraction of seeds where the stopped estimate is within TVD 0.05 of the true distribution. The secondary metric is efficiency, defined as the ratio between the relevant theoretical bound and the median number of packets collected before stopping. Additional diagnostics plot the median stopping sample count, the TVD against truth at the stopping time, and a continued trace beyond an early stopping decision. These diagnostics are included to explain why some stopping settings fail rather than merely reporting that they fail.

The evaluation reports packet counts as the primary cost because the monitor is passive. The time needed to collect a given number of samples depends on the traffic that already traverses the path. Figure \ref{fig:packet-timing-table} is therefore only a scale conversion, not an assumption that the monitor sends probes. For 1500-byte packets sent back-to-back on a 100 gigabit per second link, 1,600 packets correspond to about 192 microseconds and 3,000 packets to about 360 microseconds. On a 1 gigabit per second link the same counts correspond to 19.2 milliseconds and 36.0 milliseconds. This makes the sample counts easier to interpret: in a high-rate setting, the successful stopping configurations are not waiting for a long measurement interval, but for enough naturally observed packets to make the distribution stable.

Figure \ref{fig:adaptive-cont-correctness} shows the continuous correctness grid, with larger batch sizes higher on the vertical axis. The unsafe region is concentrated in the lower-right corner, where the monitor checks too often and accepts too much change between estimates. With \(B=100\) and \(\theta=\delta\), correctness is 0.53 for normal, 0.42 for lognormal, and 0.49 for Weibull. This is not a marginal loss. It means the rule accepts inaccurate estimates in roughly half of the trials while appearing highly efficient. Tightening the threshold to \(\theta=\delta/6\) at the same value of \(B\) raises correctness to 0.98, 0.95, and 0.97. Increasing \(B\) has a similar stabilising effect because each comparison is made after a larger cumulative sample. At \(B=200\) and \(\theta=\delta/6\), correctness is 1.00 for normal, 1.00 for lognormal, and 0.99 for Weibull. The safe region is therefore not found by maximising speed, but by excluding the part of the grid where local stability is too easy to trigger.

For the normal distribution, the most aggressive configuration, \(B=100\) and \(\theta=\delta\), has very high apparent efficiency because the median stopping time is only 200 samples. However, it is correct in only 53 percent of seeds, so it is not usable. The configuration \(B=100\) and \(\theta=\delta/6\) is much better: it reaches 98 percent correctness with median stopping time 900 and an efficiency of roughly 200 times relative to the 179,744-sample theoretical bound. The more conservative \(B=200\) and \(\theta=\delta/6\) reaches 100 percent correctness with median stopping time 1,600 and efficiency about 112 times. This is a useful operating point when reliability matters more than the last factor of efficiency.

Weibull is slightly more robust under tight thresholds, with 97 percent correctness at \(B=100,\theta=\delta/6\), but it also fails under loose thresholds because the early KDE can stabilise around an oversmoothed peak before the tail is well estimated. The important point is that the failure mode is not tied to one distributional shape. Normal, lognormal, and Weibull have different geometry, but all can produce early apparent stability when the rule is too permissive. The common safe pattern is \(B=200,\theta=\delta/6\), which reaches 1.00 correctness for normal, 1.00 for lognormal, and 0.99 for Weibull.

Figure \ref{fig:n-stop-summary-cont-all} separates packet cost from correctness. Larger values of \(B\) usually increase the median number of packets collected before stopping, because the monitor has fewer opportunities to stop and each decision is made after a larger increment. Tighter thresholds also increase the stopping time. The three distributions have similar stopping-count curves, which is useful: the operating point does not need to be tuned separately for every smooth continuous family. The difference is not mainly how long the safe settings take, but how often the unsafe settings stop before the estimate is accurate.

Moving from \(\theta=\delta\) to \(\theta=\delta/6\) increases the median stopping count from 200 packets to 900 packets, but it also moves correctness from unreliable to almost complete across all three continuous distributions. The extra cost is only a few hundred naturally observed packets, while the benefit is the removal of the false-stability regime. The monitor should therefore pay a modest sample cost to avoid accepting an estimate whose accuracy is still largely accidental.

\label{fig:early-stop-trace-cont-all}

Figure \ref{fig:early-stop-trace-cont-all} explains why the loose \(B=100,\theta=\delta\) rule fails. In the examples shown, the observed TVD to the previous estimate falls below the stopping threshold at 200 packets, so the rule stops. The upper row shows that the true TVD is still above 0.05 at that point. Continuing the same run beyond the stopping decision shows the TVD against truth falling below the target after later batches. This is the key diagnosis. The estimator is not fundamentally unable to learn the distribution, and the batch mechanism is not wrong because it compares cumulative estimates. The problem is premature trust: the first two cumulative reconstructions can be close to one another because both are under-sampled, not because both are correct. Tightening \(\theta\) or increasing \(B\) reduces this false-stability event by requiring a stronger sign of convergence before stopping.

Figure \ref{fig:adaptive-disc-correctness} shows that the discrete distributions are more demanding. At \(B=100\) and \(\theta=\delta\), correctness is only 0.13 for binomial, 0.12 for Zipf, and 0.02 for the piecewise distribution. The reason is that the PMF estimate can appear stable before enough mass has been allocated to each support point, especially when the distribution has several separated modes. Tightening the threshold helps, but the safest region is reached later than in the continuous case. With \(B=300\) and \(\theta=\delta/5\), all three discrete distributions reach 100 percent correctness, with median stopping times between 2,250 and 3,000 samples. This is still far below the corresponding worst-case learning bounds, but the efficiency gains are naturally smaller than in the continuous KDE case because the theoretical bounds for these 20-point discrete distributions are already much lower.

Appendix \ref{app:adaptive-diagnostics} includes the corresponding total-packets plot and stopping-time TVD plot for the piecewise distribution. Those diagnostics show that the piecewise case is hard because loose thresholds and small values of \(B\) leave many stopped estimates near or above the target line. With tighter thresholds or larger values of \(B\), the stopped TVD moves safely below 0.05, often around 0.02 to 0.03, leaving useful safety margin.

The adaptive stopping evaluation gives a clear deployment message. A loose stability threshold is unsafe because the estimate can look locally stable before it is globally accurate. A stricter threshold, especially \(\theta=\delta/6\) or \(\theta=\delta/5\), removes most early stopping failures at a small sample cost compared with the theoretical bound. Continuous KDE reconstruction can use \(B=100\) with a tight threshold for an aggressive configuration, or \(B=200\) with a tight threshold for a conservative one. Discrete PMF reconstruction should use a larger value of \(B\), with \(B=300\) and \(\theta=\delta/5\) giving a clean setting across the three tested distributions. The rule is therefore distribution-agnostic in the same sense as the estimator itself: it does not need to know the generating family, but the chosen operating point should reflect the desired reliability level and the estimator resolution. The evaluation also gives the later experiments a diagnostic tool. If the use case fails after this stopping rule has accepted a distribution, the likely cause is no longer basic sample convergence, but the identification boundary or the network mechanism that generated the observed delays.

This also sets up the use-case evaluation. The stopping rule is not the final operational decision. It decides when the distribution estimate is stable enough to be trusted. The use case then performs the identification step: comparing that stable estimate with a reference state or decision boundary for remaining capacity. This separation is important because it keeps two errors distinct. Early stopping error is the risk of trusting an unstable estimate, while identification error is the risk of drawing the wrong operational conclusion from a stable estimate.

\chapter{Conclusion and Future Work}

The evaluation supports the core premise of the project. Passive delay samples contain enough information to reconstruct the delay distribution, and the number of samples needed in the tested cases is much smaller than the distribution-free worst-case bound. The statistical theory explains the scaling with resolution and accuracy, while the adaptive stopping experiments show how to turn that theory into a practical online rule. The next step is to test whether the same behaviour persists in richer topologies, where multiple links, queues, and path mixtures can change the observed delay distribution without changing the monitoring interface.
