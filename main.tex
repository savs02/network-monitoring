\begin{abstract}
Knowing how much additional traffic a path can absorb before performance degrades is central to network management, yet current practice often answers this question by monitoring scalar delay metrics such as mean round-trip time or percentile latency and raising alerts when these cross predefined thresholds. These summaries discard distributional information that encodes how path conditions are changing. This report evaluates a passive monitoring system that treats the delay distribution itself as the object of interest. The evaluation first studies the statistical sample complexity behind distribution reconstruction, then evaluates an adaptive stopping rule that decides when enough samples have been collected without using ground truth at deployment time.
\end{abstract}

\section{Evaluation structure}

The methodology and evaluation are organised around the same set of questions. The full evaluation plan has five parts: statistical sample complexity, adaptive stopping, the motivating use case, multi-hop topologies, and multi-path topologies. The first two parts are developed here because they establish the statistical basis of the monitor before the network scenarios become more complex. The later use-case, multi-hop, and multi-path studies are left as separate sections so that their methodology and evaluation can follow the same structure once their experiments are complete.

\section{Statistical sample complexity}
\label{sec:method-statistical}

The first methodological question is how many passive delay samples are needed before the reconstructed delay distribution is accurate. The monitor observes independent packet delay samples from an unknown distribution and constructs an empirical reconstruction without being told which parametric family generated the samples. The main accuracy metric is total variation distance (TVD). For an unknown distribution \(P\) and an estimate \(\widehat{P}\) over a finite domain \(\mathcal{X}\), this is
\[
d_{\mathrm{TV}}(P,\widehat{P}) =
\frac{1}{2}\sum_{x \in \mathcal{X}} |P(x)-\widehat{P}(x)|.
\]
A reconstruction is treated as successful when this distance is at most a target error \(\delta\), with failure probability at most \(\varepsilon\).

The theoretical baseline comes from finite-domain distribution learning. If the distribution has support size \(k\), standard results show that the sample complexity for learning the distribution in TVD is
\[
n = \Theta\left(\frac{k+\log(1/\varepsilon)}{\delta^2}\right).
\]
This result gives the statistical backing for the \(n\)-theory experiments. It predicts that the required number of samples should grow linearly with the number of resolution cells and quadratically as the target error becomes stricter \cite{canonneShort,devroyeLugosi}. Canonne's survey also distinguishes this reconstruction task from identity testing, where the goal is only to decide whether samples match a known distribution \cite{canonneSurvey}. This project needs reconstruction rather than rejection of a candidate distribution, so the finite-domain learning result is the relevant point of comparison.

The experiment applies the finite-domain result to packet delays by choosing a delay resolution. For continuous delay distributions, the monitor uses kernel density estimation (KDE) evaluated on a 1 millisecond (ms) grid from 0 ms to 150 ms. This creates \(K=150\) evaluation cells for the theoretical comparison. For the discrete probability mass function (PMF) estimator, the same delay range is quantised into bins of width 1 ms, 2 ms, 5 ms, or 10 ms, giving \(k=150\), \(k=75\), \(k=30\), and \(k=15\). The confidence parameter is fixed at \(\varepsilon=0.05\), and the target error \(\delta\) is swept from 0.01 to 0.1.

The sample-complexity runs use the simple single-link delay setup. The continuous cases are normal, lognormal, and Weibull delay distributions. Each empirical point is the smallest tested sample size for which the median TVD across 20 random seeds is at most the target \(\delta\). This design deliberately separates two questions. The theoretical curve asks what is guaranteed for an arbitrary distribution over the chosen number of cells. The empirical curve asks how many samples are needed for the structured delay distributions used by the monitor. The difference between these curves is therefore expected to be informative rather than problematic.

The methodology also includes two supporting diagnostics. First, the bin-resolution experiment varies the number of delay cells to test the predicted dependence on \(k\). Second, one-sample Kolmogorov-Smirnov tests are used as secondary diagnostics for convergence. These tests are not used as the primary success criterion because the monitor's objective is distribution reconstruction in TVD, but they provide a useful independent check that the empirical samples converge towards the configured ground truth as \(n\) grows.

\section{Adaptive stopping}
\label{sec:method-adaptive}

The second methodological question is how a passive monitor can decide when to stop collecting samples without access to ground truth. The statistical sample-complexity bound gives a conservative distribution-free reference point, but it cannot be used directly as an efficient deployment rule. The monitor therefore uses a stability-based stopping rule. The rule compares two consecutive reconstructions and stops when the estimate changes by less than a chosen threshold.

Samples are processed in groups of \(B\) packets, where \(B\) is the packets per batch parameter. After each new group of packets, the monitor computes the TVD between the current estimate and the previous estimate. If this inter-estimate TVD falls below a threshold \(\theta\), the monitor stops:
\[
\tau = \inf\left\{mB : d_{\mathrm{TV}}\left(\widehat{F}_{mB}, \widehat{F}_{(m-1)B}\right) < \theta\right\}.
\]
The stopping rule does not use the true distribution. Ground truth is used only after a run has stopped to evaluate whether the stopped estimate satisfies \(d_{\mathrm{TV}}(\widehat{F}_{\tau},F)\leq\delta\), where the target is \(\delta=0.05\).

The adaptive stopping sweep tests eight choices for packets per batch, \(B \in \{100,200,300,500,750,1000,1500,2000\}\), and six stability thresholds, \(\theta \in \{\delta/6,\delta/5,\delta/4,\delta/3,\delta/2,\delta\}\). Each configuration is evaluated over 100 random seeds. The continuous group uses the same normal, lognormal, and Weibull distributions as the sample-complexity experiment, reconstructed with KDE on the 1 ms grid. The discrete group uses a binomial distribution, a truncated Zipf distribution, and a hand-built multi-modal piecewise distribution over roughly 20 support points, reconstructed with a PMF estimator.

This design tests two distinct failure modes. Small values of \(B\) give the monitor more chances to stop, but each decision is based on a noisier change between estimates. Loose thresholds can make an estimate appear stable before it is accurate. The discrete distributions test a harder shape regime, because separated modes can make a PMF estimate look locally stable before enough probability mass has been assigned to every relevant support point.

The primary adaptive metric is correctness, defined as the fraction of seeds where the stopped estimate is within TVD 0.05 of the true distribution. The secondary metric is efficiency, defined as the ratio between the relevant theoretical bound and the median number of packets collected before stopping. Additional diagnostics plot the median stopping sample count, the TVD against truth at the stopping time, and a continued trace beyond an early stopping decision. These diagnostics are included to explain why some stopping settings fail rather than merely reporting that they fail.

\section{Statistical sample complexity}
\label{sec:eval-statistical}

The statistical sample-complexity evaluation tests whether the monitor behaves in the way predicted by the learning theory. The purpose is not to show that the worst-case theorem is tight for the tested delay distributions. Instead, the experiment asks whether the qualitative dependencies in the theory are visible in practice. If the empirical sample requirement rises as \(\delta\) becomes smaller and falls as the number of delay cells decreases, then the \(n\)-theory analysis is a useful guide for the design of the monitor even when the absolute bound is conservative.

The experiment is motivated by two design choices. The first is the choice of estimator. KDE can share information across neighbouring delay values, while PMF estimation treats each bin as a separate category. The second is the choice of resolution. A fine grid preserves more distributional detail, but it increases the number of probabilities that must be estimated. The plots in this section therefore compare KDE and PMF estimation across both target error and bin width.

\begin{figure}[htbp]
\centering
\includegraphics[width=\textwidth]{n_vs_delta_main.png}
\caption{Theoretical and empirical sample requirements as the TVD target varies. The left panel shows the KDE estimator on the 1 ms grid. The right panels show the PMF estimator at 1 ms, 2 ms, 5 ms, and 10 ms bin widths.}
\label{fig:n-vs-delta-main}
\end{figure}

Figure \ref{fig:n-vs-delta-main} confirms the expected shape of the theory. Tightening \(\delta\) increases the number of required samples approximately according to the \(1/\delta^2\) rate, and reducing the number of bins lowers the discrete theoretical bound. The important practical result is that the theoretical curves remain conservative for the distributions used in this evaluation. At \(\delta=0.05\), the continuous bound with \(K=150\) is 179,744 samples, while the empirical KDE requirement is 500 samples for all three tested continuous distributions. For the 1 ms PMF estimator, the theoretical bound is 61,199 samples, while the empirical requirement is 1,000 samples for the normal and lognormal cases and 2,000 samples for the Weibull case. At 10 ms resolution, the theoretical bound falls to 7,199 samples and the empirical requirement is already 100 samples for all three distributions.

The gap between the bound and the empirical curves is not a failure of the theory. The theorem protects against worst-case distributions over \(k\) cells. The tested delay distributions are much more structured than an arbitrary distribution over 150 unrelated categories. The normal and lognormal distributions concentrate their mass smoothly, while the Weibull distribution has a sharper asymmetric peak and a longer region of lower-density tail. This explains why Weibull is consistently the hardest case for the 1 ms PMF estimator. Its mass is spread in a way that makes fine histogram counts noisier, so more samples are needed before every relevant bin has stabilised. Appendix \ref{app:statistical-diagnostics} gives the supporting TVD, bin-resolution, and hypothesis-test plots.

\begin{figure}[htbp]
\centering
\includegraphics[width=\textwidth]{n_vs_delta_overlay.png}
\caption{Comparison between KDE and PMF using 1 ms bins. The empirical KDE lines sit below the empirical PMF lines in the small-sample regime, especially for the Weibull distribution.}
\label{fig:kde-pmf-overlay}
\end{figure}

Figure \ref{fig:kde-pmf-overlay} compares the continuous KDE estimator with the 1 ms PMF estimator. KDE is more sample efficient in these experiments because it uses smoothness across neighbouring delay values, while the PMF estimator treats adjacent bins as separate categories. This is most visible for Weibull, where the KDE empirical requirement is 500 samples at \(\delta=0.05\) but the 1 ms PMF requirement is 2,000 samples. The result is useful for the monitoring design because it shows that an estimator can use structure in delay data without assuming the parametric family that generated it.

The PMF results also show the cost of resolution. Finer bins preserve more detail, but each bin introduces another probability to estimate. Coarser bins reduce the statistical burden, but they also discard within-bin structure. In this experiment, 1 ms bins are already fine enough that the PMF and KDE reconstructions become similar at larger \(n\), while 5 ms and 10 ms bins make the monitor cheaper but less faithful to the continuous shape. The KDE versus PMF comparison therefore suggests a practical rule: use a fine grid when the goal is to reconstruct the delay shape, and use coarser bins only when the application is explicitly tolerant of lower resolution. The supporting estimator-disagreement and KDE-advantage plots are included in Appendix \ref{app:statistical-diagnostics}; they show the same trend without changing the main conclusion.

The total variation results are also supported by hypothesis-test diagnostics. The one-sample Kolmogorov-Smirnov statistic decreases approximately as \(1/\sqrt{n}\), and the pass-rate view aligns with the sample sizes where median TVD first reaches 0.05. Those plots are useful checks, but they are secondary to the reconstruction metric, so they are included in the appendix rather than in the main evaluation flow.

Overall, the statistical evaluation validates the use of total variation distance as the primary reconstruction metric. The results match the theory in their dependence on \(k\), \(\delta\), and \(n\), but the absolute worst-case bounds are too conservative to be used directly as deployment stopping thresholds. That conservatism motivates the second part of the evaluation. If the monitor can detect when its own estimate has stabilised, it may stop far earlier than the distribution-free bound while still meeting the target TVD in practice.

\section{Adaptive stopping}
\label{sec:eval-adaptive}

The adaptive stopping evaluation tests whether stability between consecutive estimates is a reliable proxy for accuracy against the true distribution. This matters because the previous section uses ground truth to measure when a reconstruction becomes accurate, but a deployed passive monitor cannot observe ground truth. The stopping rule is therefore useful only if it stops early while still meeting the TVD target with high probability.

The experiment focuses on the trade-off between reliability and packet cost. Small values of \(B\) can stop quickly but are more vulnerable to noisy local stability. Loose thresholds stop quickly for the same reason, but they can accept a reconstruction before it has converged globally. The continuous and discrete distribution groups are evaluated separately because they stress different aspects of the estimator. Continuous KDE benefits from smoothness, while discrete PMF estimation must place mass correctly across separate support points.

\begin{figure}[htbp]
\centering
\includegraphics[width=\textwidth]{correctness_grid_cont.png}
\caption{Correctness of the adaptive stopping rule for the continuous distributions. Each cell is the fraction of 100 seeds where the stopped estimate is within TVD 0.05 of the true distribution.}
\label{fig:adaptive-cont-correctness}
\end{figure}

Figure \ref{fig:adaptive-cont-correctness} shows the continuous correctness grid. Loose thresholds and small values of \(B\) can stop too early. With \(B=100\) and \(\theta=\delta\), correctness is 0.53 for normal, 0.42 for lognormal, and 0.49 for Weibull. Tightening the threshold to \(\theta=\delta/6\) at the same value of \(B\) raises correctness to 0.98, 0.95, and 0.97. Increasing \(B\) makes the rule more reliable because the change between successive estimates is less dominated by sampling noise. At \(B=200\) and \(\theta=\delta/6\), correctness is 1.00 for normal, 1.00 for lognormal, and 0.99 for Weibull. From \(B=500\) onwards, the continuous grid is almost entirely correct even for looser thresholds.

\begin{figure}[htbp]
\centering
\includegraphics[width=\textwidth]{heatmap_cont_normal.png}
\caption{Correctness and efficiency for the normal distribution. Efficiency is the ratio between the theoretical bound and the median stopping sample size.}
\label{fig:adaptive-normal-efficiency}
\end{figure}

Figure \ref{fig:adaptive-normal-efficiency} shows why the stopping problem is a trade-off rather than a single optimum. For the normal distribution, the most aggressive configuration, \(B=100\) and \(\theta=\delta\), has very high apparent efficiency because the median stopping time is only 200 samples. However, it is correct in only 53 percent of seeds, so it is not usable. The configuration \(B=100\) and \(\theta=\delta/6\) is much better: it reaches 98 percent correctness with median stopping time 900 and an efficiency of roughly 200 times relative to the 179,744-sample theoretical bound. The more conservative \(B=200\) and \(\theta=\delta/6\) reaches 100 percent correctness with median stopping time 1,600 and efficiency about 112 times. This is a useful operating point when reliability matters more than the last factor of efficiency.

\begin{figure}[htbp]
\centering
\includegraphics[width=0.92\textwidth]{n_stop_summary_cont_normal.png}
\caption{Median total packets collected before stopping for the normal distribution. Shading shows the interquartile range across seeds, and the dotted line shows the theoretical sample bound.}
\label{fig:n-stop-summary-normal}
\end{figure}

Figure \ref{fig:n-stop-summary-normal} separates the packet cost from the correctness heatmap. Larger values of \(B\) usually increase the median number of packets collected before stopping, because the monitor has fewer opportunities to stop and each decision is made after a larger increment. Tighter thresholds also increase the stopping time. The curve shows why \(B=200,\theta=\delta/6\) is a conservative operating point: it uses more packets than the aggressive \(B=100\) setting, but it remains orders of magnitude below the theoretical bound while reaching full correctness in the normal and lognormal cases.

\begin{figure}[htbp]
\centering
\includegraphics[width=\textwidth]{early_stop_trace_normal.png}
\caption{A continued trace after the stopping point for one normal run. The loose \(B=100,\theta=\delta\) rule stops while the true TVD is still above the target, while tighter rules continue until the reconstruction has stabilised.}
\label{fig:early-stop-trace-normal}
\end{figure}

Figure \ref{fig:early-stop-trace-normal} shows the mechanism behind early stopping. The lower panel plots the TVD between successive estimates, which is the quantity the stopping rule actually observes. With \(B=100\) and \(\theta=\delta\), this quantity falls below the threshold after 200 packets, so the rule stops. The upper panel shows the post-hoc truth: at that point the true reconstruction error is still above 0.05. Continuing the same run shows that the true TVD falls below the target after more packets. The strict \(B=100,\theta=\delta/6\) rule and the larger values of \(B\) therefore avoid the failure by requiring stronger evidence of stability.

\begin{figure}[htbp]
\centering
\includegraphics[width=\textwidth]{correctness_grid_disc.png}
\caption{Correctness of adaptive stopping for the discrete distributions. The multi-modal piecewise distribution is the hardest case.}
\label{fig:adaptive-disc-correctness}
\end{figure}

Figure \ref{fig:adaptive-disc-correctness} shows that the discrete distributions are more demanding. At \(B=100\) and \(\theta=\delta\), correctness is only 0.13 for binomial, 0.12 for Zipf, and 0.02 for the piecewise distribution. The reason is that the PMF estimate can appear stable before enough mass has been allocated to each support point, especially when the distribution has several separated modes. Tightening the threshold helps, but the safest region is reached later than in the continuous case. With \(B=300\) and \(\theta=\delta/5\), all three discrete distributions reach 100 percent correctness, with median stopping times between 2,250 and 3,000 samples. This is still far below the corresponding worst-case learning bounds, but the efficiency gains are naturally smaller than in the continuous KDE case because the theoretical bounds for these 20-point discrete distributions are already much lower.

Appendix \ref{app:adaptive-diagnostics} includes the corresponding total-packets plot and stopping-time TVD plot for the piecewise distribution. Those diagnostics show that the piecewise case is hard because loose thresholds and small values of \(B\) leave many stopped estimates near or above the target line. With tighter thresholds or larger values of \(B\), the stopped TVD moves safely below 0.05, often around 0.02 to 0.03, leaving useful safety margin.

The adaptive stopping evaluation gives a clear deployment message. A loose stability threshold is unsafe because the estimate can look locally stable before it is globally accurate. A modestly stricter threshold, especially \(\theta=\delta/6\) or \(\theta=\delta/5\), removes most early stopping failures. Continuous KDE reconstruction can use \(B=100\) with a tight threshold for an aggressive configuration, or \(B=200\) with a tight threshold for a conservative one. Discrete PMF reconstruction should use a larger value of \(B\), with \(B=300\) and \(\theta=\delta/5\) giving a clean setting across the three tested distributions. The rule is therefore distribution-agnostic in the same sense as the estimator itself: it does not need to know the generating family, but the chosen operating point should reflect the desired reliability level and the estimator resolution.

\chapter{Conclusion and Future Work}

The evaluation supports the core premise of the project. Passive delay samples contain enough information to reconstruct the delay distribution, and the number of samples needed in the tested cases is much smaller than the distribution-free worst-case bound. The statistical theory explains the scaling with resolution and accuracy, while the adaptive stopping experiments show how to turn that theory into a practical online rule. The next step is to test whether the same behaviour persists in richer topologies, where multiple links, queues, and path mixtures can change the observed delay distribution without changing the monitoring interface.
