\begin{abstract}
Knowing how much additional traffic a path can absorb before performance degrades is central to network management, yet current practice often answers this question by monitoring scalar delay metrics such as mean round-trip time or percentile latency and raising alerts when these cross predefined thresholds. These summaries discard distributional information that encodes how path conditions are changing. This report evaluates a passive monitoring system that treats the delay distribution itself as the object of interest. The evaluation first studies the statistical sample complexity behind distribution reconstruction, then evaluates an adaptive stopping rule that decides when enough samples have been collected without using ground truth at deployment time.
\end{abstract}

\section{Statistical sample complexity}
\label{sec:eval-statistical}

The first evaluation asks how many samples are needed before an unknown delay distribution can be reconstructed accurately. This part deliberately removes the network simulator from the loop. Samples are drawn directly from the configured distributions so that the statistical claim can be tested before any network effects are added. The monitor sees only samples. It is not told whether they came from a binomial, Zipfian, piecewise, normal, lognormal, or Weibull distribution.

The main accuracy metric is total variation distance (TVD). For a true distribution \(P\) and an estimate \(\widehat{P}\) over a finite domain \(\mathcal{X}\), this is
\[
d_{\mathrm{TV}}(P,\widehat{P}) =
\frac{1}{2}\sum_{x \in \mathcal{X}} |P(x)-\widehat{P}(x)|.
\]
A reconstruction is treated as successful when this distance is at most a target error \(\delta\), with failure probability at most \(\varepsilon\). Throughout this section, \(\delta=0.05\) and \(\varepsilon=0.05\), so the target is reconstruction within 5 percent TVD with probability at least 0.95.

\subsection{The learning bound}

The theoretical reference point comes from finite-domain distribution learning. The statistical learning notes identify this as the relevant distribution reconstruction problem and point to Canonne's treatment of learning and testing discrete distributions. Given independent samples from an unknown distribution over \(k\) possible outcomes, the plug-in histogram estimator can learn the distribution in TVD with sample complexity
\[
n = \Theta\left(\frac{k+\log(1/\varepsilon)}{\delta^2}\right).
\]
This is an information-theoretic finite-sample bound, tight up to universal constants for arbitrary distributions on \(k\) categories \cite{canonneShort,canonneTopics,devroyeLugosi}. The \(k\) term is the number of probabilities that must be estimated. The \(1/\delta^2\) term comes from concentration: halving the desired error requires roughly four times as many samples. The \(\log(1/\varepsilon)\) term pays for high probability rather than only average-case accuracy.

This is the correct baseline because the monitor is reconstructing the full distribution. It is not doing identity testing. Identity testing asks whether samples match a known candidate distribution and has a different sample complexity with a \(\sqrt{k}\) dependence \cite{canonneSurvey}. That easier problem is not enough here, because the deployed monitor does not know a candidate ground truth distribution in advance.

The word finite is important. A discrete distribution already has a finite support. A continuous delay distribution has to be evaluated on a finite grid before TVD can be computed as a sum. A bin is one such grid cell. In the continuous experiments below, one bin corresponds to a one millisecond interval, and all bins from 0 milliseconds to 150 milliseconds are used. This gives \(k=150\) categories. Once the continuous distribution has been converted into bin probabilities, the same finite-domain comparison applies.

The experiments use the explicit reference value
\[
n_{\mathrm{theory}} =
\left\lceil \frac{k+\log(1/\varepsilon)}{\delta^2} \right\rceil .
\]
With \(\varepsilon=0.05\), \(\log(1/\varepsilon)=\log(20)=2.996\). The corresponding theory curve in the plots is the same relationship inverted as
\[
\delta_{\mathrm{theory}}(n)=
\sqrt{\frac{k+\log(1/\varepsilon)}{n}}.
\]
The curve should be read as a distribution-free reference, not as a prediction that every structured distribution will need exactly that many samples. The main empirical pattern to look for is therefore not equality between the curves, but whether TVD falls with \(n\), whether harder shapes converge more slowly, and whether the target is reached no later than the calculated reference point.

\subsection{Discrete sampling}

The discrete experiment uses three finite distributions, shown in the top row of Figure \ref{fig:statistical-distribution-shapes}. They were chosen because the theorem is stated directly for finite domains, and because they stress different forms of discrete structure. The binomial distribution is smooth and concentrated. The Zipfian distribution is highly skewed and has a long finite tail of rare outcomes. The piecewise distribution is deliberately irregular and multi-modal, so it tests a case where there is no smooth ordering for the estimator to exploit.

The binomial case uses
\[
X \sim \mathrm{Binomial}(20,0.5),
\qquad
p(x)=\binom{20}{x}0.5^x0.5^{20-x},
\qquad x \in \{0,\ldots,20\}.
\]
This gives \(k=21\) possible outcomes. The Zipfian case uses a truncated power law,
\[
p(x)=\frac{x^{-1.5}}{\sum_{j=1}^{20}j^{-1.5}},
\qquad x \in \{1,\ldots,20\},
\]
so \(k=20\). The piecewise case also uses support \(\{1,\ldots,20\}\), with probabilities indexed in support order as
\[
\begin{aligned}
p = (&0.12,0.02,0.08,0.01,0.10,0.03,0.07,0.12,0.02,0.09,\\
     &0.01,0.08,0.04,0.06,0.02,0.05,0.02,0.04,0.01,0.01).
\end{aligned}
\]
The values sum to one and create separated high-probability regions.

For each distribution, samples are drawn directly from the probability mass function (PMF). The estimator is the empirical PMF. Each point in Figure \ref{fig:statistical-discrete-tvd} is the median TVD over 100 random seeds, and the shaded band is the interquartile range. The tested sample sizes are centred around the calculated \(n_{\mathrm{theory}}\) value for each support size.

The calculation for the binomial case is
\[
n_{\mathrm{theory}} =
\left\lceil \frac{21+\log(20)}{0.05^2} \right\rceil
=
\left\lceil \frac{23.996}{0.0025} \right\rceil
= 9{,}599.
\]
For the Zipfian and piecewise cases, \(k=20\), so
\[
n_{\mathrm{theory}} =
\left\lceil \frac{20+\log(20)}{0.05^2} \right\rceil
=
\left\lceil \frac{22.996}{0.0025} \right\rceil
= 9{,}199.
\]

Figure \ref{fig:statistical-discrete-tvd} shows the expected monotone decrease in TVD as \(n\) grows. The empirical curves all fall below the target well before the calculated reference point, but the ranking across distributions is meaningful. The binomial distribution is the easiest of the three. Although it has one more support point than the others, most of its mass is concentrated near the centre, so the low-probability tails contribute little to TVD. It first reaches the target at \(n=960\), and by \(n_{\mathrm{theory}}=9{,}599\) the median TVD is 0.0123.

The Zipfian distribution reaches the target at \(n=920\) and has median TVD 0.0132 at its theory point. Its head is easy to estimate because the first few outcomes carry most of the mass. The rare tail outcomes are harder individually, but their combined probability is limited, so errors in the tail do not dominate TVD. This is why the Zipfian curve is close to the binomial curve despite having a more uneven shape.

The piecewise distribution is the hardest discrete case. It is still below the theoretical reference by a wide margin, but it needs \(n=2{,}300\) samples before the median TVD falls below 0.05. This behaviour matches the design of the distribution. Probability mass is spread across separated peaks and troughs, so the empirical PMF has to learn several non-neighbouring support points accurately. The result is useful because it shows that the theoretical bound is not only conservative for smooth distributions. Even an irregular finite distribution reaches the target before the calculated distribution-free sample count, but it does so later than the smoother and more skewed alternatives.

\subsection{Continuous sampling}

The continuous experiment uses the normal, lognormal, and Weibull distributions shown in the bottom row of Figure \ref{fig:statistical-distribution-shapes}. These are the same families used elsewhere in the project because they cover three different delay shapes. The normal distribution is symmetric and concentrated, representing a low-variability delay regime. The lognormal distribution is positive and right-skewed, which is a common shape for multiplicative delay effects. The Weibull distribution is also positive but has a different asymmetric shape, with a sharp rise and a longer decaying tail.

The parameter choices are
\[
X_{\mathrm{normal}} \sim \mathcal{N}(40,2^2),
\qquad
\log X_{\mathrm{lognormal}} \sim \mathcal{N}(2.3,0.2^2),
\qquad
X_{\mathrm{weibull}} \sim \mathrm{Weibull}(\lambda=10,\alpha=2).
\]
All samples are evaluated on the same one millisecond grid from 0 milliseconds to 150 milliseconds. The true binned distribution is computed by integrating the known cumulative distribution function over each bin. The empirical PMF counts how many samples fall in each bin. The kernel density estimate (KDE) is computed from the same samples, evaluated at the bin centres, and normalised so that it can also be compared as a probability mass function on the grid. This matters because TVD compares probability mass, not raw continuous density values.

The finite-grid comparison has \(k=150\), so the calculated bound is
\[
n_{\mathrm{theory}} =
\left\lceil \frac{150+\log(20)}{0.05^2} \right\rceil
=
\left\lceil \frac{152.996}{0.0025} \right\rceil
= 61{,}199.
\]
Each point in Figure \ref{fig:statistical-continuous-tvd} is the median across 30 random seeds, with interquartile shading.

The continuous results show the same broad pattern as the discrete results. TVD falls as the number of samples grows, and all three distributions are well below the target by the calculated \(n_{\mathrm{theory}}\). The empirical PMF reaches the target at 500 samples for the normal distribution, 1,000 samples for the lognormal distribution, and 2,000 samples for the Weibull distribution. The ordering is intuitive. The normal distribution places most mass in a narrow symmetric region, so the important bins are quickly populated. The lognormal distribution is skewed, which makes its right tail noisier. The Weibull distribution is the hardest for the binned PMF because its mass rises sharply near the lower end and then decays over a longer range, so the histogram has to estimate both a peak and a tail.

KDE changes this picture in the low-sample regime. It reaches the 0.05 target at the first tested point, 500 samples, for all three continuous distributions. This does not mean KDE has been given the parametric family. It only uses the local smoothness of nearby delay values. The empirical PMF treats adjacent one millisecond bins as unrelated categories, while KDE shares information across neighbouring values. That smoothing is especially helpful for Weibull, where the PMF median TVD is 0.0875 at 500 samples but the KDE median TVD is 0.0421.

At the theory point, both estimators are much more accurate than required. The binned PMF medians are 0.0047 for normal, 0.0052 for lognormal, and 0.0073 for Weibull. The KDE medians are 0.0060, 0.0057, and 0.0058. The small reversal for normal and lognormal, where the PMF is slightly closer than KDE at very large \(n\), is also expected. Once many samples have populated the bins, the empirical PMF has little variance left, while KDE still introduces a small amount of smoothing bias. The practical conclusion is therefore not that KDE always dominates PMF. It is that KDE is more sample efficient at the target accuracy used here, while PMF becomes competitive once the sample count is already large.

Figure \ref{fig:statistical-kde-pmf-gap} directly compares the two continuous reconstructions. The gap between the binned PMF and KDE falls with \(n\), from 0.0704 to 0.0039 in the Weibull case and from roughly 0.03 to 0.003 in the normal and lognormal cases. This shows that KDE is not reconstructing a fundamentally different object. It is a smoothed version of the same empirical information, and the two estimates agree once enough samples are available.

The main implication for the monitor is that the theoretical bound is useful as a statistical backstop but too conservative as a stopping rule. It correctly identifies the dependence on support size, confidence, and error tolerance, and the empirical curves behave in the direction predicted by the theory. However, the direct-sampling distributions are far more structured than an arbitrary distribution over \(k\) unrelated cells. Their smoothness, concentration, and skew all affect how quickly TVD falls. This gap between worst-case theory and observed convergence motivates the adaptive stopping evaluation in the next section: instead of always waiting for \(n_{\mathrm{theory}}\), the monitor should stop when the estimate itself has stabilised.

The older delta-sweep, bin-resolution, KDE-disagreement, and Kolmogorov-Smirnov diagnostics are kept in Appendix \ref{app:statistical-diagnostics}. They support the same conclusion from a wider set of views: stricter TVD targets and finer grids increase the theoretical sample requirement, while the empirical structured distributions usually converge much earlier than the worst-case finite-domain reference.

\section{Adaptive stopping}
\label{sec:eval-adaptive}

The second evaluation asks how a passive monitor can decide when to stop collecting samples without access to ground truth. The statistical sample-complexity bound gives a conservative distribution-free reference point, but it cannot be used directly as an efficient deployment rule. The monitor therefore uses a stability-based stopping rule. The rule compares two consecutive reconstructions and stops when the estimate changes by less than a chosen threshold.

Samples are processed in groups of \(B\) packets, where \(B\) is the packets per batch parameter. After each new group of packets, the monitor computes the TVD between the current estimate and the previous estimate. If this inter-estimate TVD falls below a threshold \(\theta\), the monitor stops:
\[
\tau = \inf\left\{mB : d_{\mathrm{TV}}\left(\widehat{F}_{mB}, \widehat{F}_{(m-1)B}\right) < \theta\right\}.
\]
The stopping rule does not use the true distribution. Ground truth is used only after a run has stopped to evaluate whether the stopped estimate satisfies \(d_{\mathrm{TV}}(\widehat{F}_{\tau},F)\leq\delta\), where the target is \(\delta=0.05\).

The adaptive stopping sweep tests eight choices for packets per batch, \(B \in \{100,200,300,500,750,1000,1500,2000\}\), and six stability thresholds, \(\theta \in \{\delta/6,\delta/5,\delta/4,\delta/3,\delta/2,\delta\}\). Each configuration is evaluated over 100 random seeds. The continuous group uses the same normal, lognormal, and Weibull distributions as the sample-complexity experiment, reconstructed with KDE on the 1 ms grid. The discrete group uses a binomial distribution, a truncated Zipf distribution, and a hand-built multi-modal piecewise distribution over roughly 20 support points, reconstructed with a PMF estimator.

The evaluation tests whether stability between consecutive estimates is a reliable proxy for accuracy against the true distribution. This matters because the previous section uses ground truth to measure when a reconstruction becomes accurate, but a deployed passive monitor cannot observe ground truth. The stopping rule is therefore useful only if it stops early while still meeting the TVD target with high probability.

The experiment focuses on the trade-off between reliability and packet cost. Small values of \(B\) can stop quickly but are more vulnerable to noisy local stability. Loose thresholds stop quickly for the same reason, but they can accept a reconstruction before it has converged globally. The continuous and discrete distribution groups are evaluated separately because they stress different aspects of the estimator. Continuous KDE benefits from smoothness, while discrete PMF estimation must place mass correctly across separate support points.

This design tests two distinct failure modes. Small values of \(B\) give the monitor more chances to stop, but each decision is based on a noisier change between estimates. Loose thresholds can make an estimate appear stable before it is accurate. The discrete distributions test a harder shape regime, because separated modes can make a PMF estimate look locally stable before enough probability mass has been assigned to every relevant support point.

The primary adaptive metric is correctness, defined as the fraction of seeds where the stopped estimate is within TVD 0.05 of the true distribution. The secondary metric is efficiency, defined as the ratio between the relevant theoretical bound and the median number of packets collected before stopping. Additional diagnostics plot the median stopping sample count, the TVD against truth at the stopping time, and a continued trace beyond an early stopping decision. These diagnostics are included to explain why some stopping settings fail rather than merely reporting that they fail.

Figure \ref{fig:adaptive-cont-correctness} shows the continuous correctness grid. Loose thresholds and small values of \(B\) can stop too early. With \(B=100\) and \(\theta=\delta\), correctness is 0.53 for normal, 0.42 for lognormal, and 0.49 for Weibull. Tightening the threshold to \(\theta=\delta/6\) at the same value of \(B\) raises correctness to 0.98, 0.95, and 0.97. Increasing \(B\) makes the rule more reliable because the change between successive estimates is less dominated by sampling noise. At \(B=200\) and \(\theta=\delta/6\), correctness is 1.00 for normal, 1.00 for lognormal, and 0.99 for Weibull. From \(B=500\) onwards, the continuous grid is almost entirely correct even for looser thresholds.

Figure \ref{fig:adaptive-normal-efficiency} shows why the stopping problem is a trade-off rather than a single optimum. For the normal distribution, the most aggressive configuration, \(B=100\) and \(\theta=\delta\), has very high apparent efficiency because the median stopping time is only 200 samples. However, it is correct in only 53 percent of seeds, so it is not usable. The configuration \(B=100\) and \(\theta=\delta/6\) is much better: it reaches 98 percent correctness with median stopping time 900 and an efficiency of roughly 200 times relative to the 179,744-sample theoretical bound. The more conservative \(B=200\) and \(\theta=\delta/6\) reaches 100 percent correctness with median stopping time 1,600 and efficiency about 112 times. This is a useful operating point when reliability matters more than the last factor of efficiency.

The curve shows why \(B=200,\theta=\delta/6\) is a conservative operating point: it uses more packets than the aggressive \(B=100\) setting, but it remains orders of magnitude below the theoretical bound while reaching full correctness in the normal and lognormal cases.

The strict \(B=100,\theta=\delta/6\) rule and the larger values of \(B\) therefore avoid the failure by requiring stronger evidence of stability.

Figure \ref{fig:adaptive-disc-correctness} shows that the discrete distributions are more demanding. At \(B=100\) and \(\theta=\delta\), correctness is only 0.13 for binomial, 0.12 for Zipf, and 0.02 for the piecewise distribution. The reason is that the PMF estimate can appear stable before enough mass has been allocated to each support point, especially when the distribution has several separated modes. Tightening the threshold helps, but the safest region is reached later than in the continuous case. With \(B=300\) and \(\theta=\delta/5\), all three discrete distributions reach 100 percent correctness, with median stopping times between 2,250 and 3,000 samples. This is still far below the corresponding worst-case learning bounds, but the efficiency gains are naturally smaller than in the continuous KDE case because the theoretical bounds for these 20-point discrete distributions are already much lower.

Appendix \ref{app:adaptive-diagnostics} includes the corresponding total-packets plot and stopping-time TVD plot for the piecewise distribution. Those diagnostics show that the piecewise case is hard because loose thresholds and small values of \(B\) leave many stopped estimates near or above the target line. With tighter thresholds or larger values of \(B\), the stopped TVD moves safely below 0.05, often around 0.02 to 0.03, leaving useful safety margin.

The adaptive stopping evaluation gives a clear deployment message. A loose stability threshold is unsafe because the estimate can look locally stable before it is globally accurate. A modestly stricter threshold, especially \(\theta=\delta/6\) or \(\theta=\delta/5\), removes most early stopping failures. Continuous KDE reconstruction can use \(B=100\) with a tight threshold for an aggressive configuration, or \(B=200\) with a tight threshold for a conservative one. Discrete PMF reconstruction should use a larger value of \(B\), with \(B=300\) and \(\theta=\delta/5\) giving a clean setting across the three tested distributions. The rule is therefore distribution-agnostic in the same sense as the estimator itself: it does not need to know the generating family, but the chosen operating point should reflect the desired reliability level and the estimator resolution.

\chapter{Conclusion and Future Work}

The evaluation supports the core premise of the project. Passive delay samples contain enough information to reconstruct the delay distribution, and the number of samples needed in the tested cases is much smaller than the distribution-free worst-case bound. The statistical theory explains the scaling with resolution and accuracy, while the adaptive stopping experiments show how to turn that theory into a practical online rule. The next step is to test whether the same behaviour persists in richer topologies, where multiple links, queues, and path mixtures can change the observed delay distribution without changing the monitoring interface.
